SpectraDerm — Module K: Spectral Visualization Report
======================================================

Module:
K — Spectral Visualization

Phase:
Phase 3 — Spectral Reconstruction and Analysis

Status:
Technically Completed

1. OBJECTIVE
------------

Module K provides visualization of the AI-estimated spectral information
generated by the SpectraDerm spectral reconstruction module.

The purpose is to make the reconstructed spectral output understandable
through visual representations while clearly distinguishing estimated
spectral information from directly measured hyperspectral data.

The module supports:

- Display of the original RGB facial image.
- Display of an AI-estimated spectral representation.
- Visualization of selected reconstructed spectral bands.
- Visualization of spectral curves from selected image regions.
- Comparison of RGB appearance with reconstructed spectral information.
- Visualization of reconstruction differences where ground-truth
  hyperspectral data are available.
- Interactive exploration of reconstructed wavelengths.

The visualization is intended for analysis and demonstration and is not
itself a diagnostic system.


2. IMPLEMENTATION
-----------------

The visualization functionality was implemented in:

src/spectraderm/spectral/visualization.py

The implementation provides the following main functionality:

- Validation of spectral cubes.
- Mapping wavelengths to reconstructed band indices.
- Extraction of individual spectral bands.
- Normalization of spectral bands for visualization.
- Conversion of selected spectral bands into a false-color representation.
- Extraction of average spectral curves from selected image regions.
- Quantitative comparison between reconstructed spectra and available
  ground-truth spectra.


3. SPECTRAL OUTPUT
------------------

The current SpectraDerm reconstruction pipeline uses the Hyper-Skin VIS
configuration.

Input:
RGB image with 3 channels.

Output:
31-band AI-estimated spectral image.

Spectral range:
400–700 nm.

Spectral interval:
10 nm.

The reconstructed cube therefore contains 31 estimated VIS bands:

400, 410, 420, 430, 440, 450, 460, 470, 480, 490,
500, 510, 520, 530, 540, 550, 560, 570, 580, 590,
600, 610, 620, 630, 640, 650, 660, 670, 680, 690,
700 nm.


4. VISUALIZATION COMPONENTS
---------------------------

4.1 Original RGB Image

The original facial RGB image is displayed as the reference visual input
to the reconstruction pipeline.


4.2 AI-Estimated Spectral Representation

A false-color representation is generated from selected reconstructed
spectral bands.

The current default representation uses:

Red channel   = 650 nm
Green channel = 550 nm
Blue channel  = 450 nm

This representation is only a visualization of reconstructed spectral
information.

It must NOT be interpreted as an actual NIR image or as directly measured
hyperspectral data.


4.3 Individual Spectral Bands

The visualization interface allows individual reconstructed bands to be
examined.

Example wavelengths include:

- 400 nm
- 450 nm
- 500 nm
- 550 nm
- 600 nm
- 650 nm
- 700 nm

This allows differences in reconstructed spatial patterns across
wavelengths to be visually inspected.


4.4 Spectral Curves

A selected facial region can be used to calculate an average spectral
curve.

The curve represents the estimated spectral response of the selected
region across the 31 reconstructed VIS wavelengths.

The region selector allows the user to change the location and size of
the analyzed region.


4.5 Ground-Truth Comparison

Where paired Hyper-Skin ground-truth VIS data are available, the
reconstructed spectrum can be compared with the corresponding measured
spectral cube.

The comparison can include:

- Absolute error.
- Mean absolute error.
- Root mean squared error.
- Spectral angle mapper (SAM).
- Difference/error visualization.

This provides a technical validation view of the reconstruction rather
than a clinical interpretation.


5. INTERACTIVE DASHBOARD
------------------------

A combined visualization dashboard was created containing:

1. Original RGB image
2. AI-estimated spectral information
3. Selected reconstructed spectral band
4. Estimated spectral curve from a selected facial region

The dashboard also displays an explicit safety disclaimer:

"AI-estimated spectral information"

and:

"Not an actual NIR image.
Spectral estimates are not disease diagnoses."


6. TEST IMAGE RESULTS
---------------------

A facial RGB image was processed through the reconstruction pipeline.

The processed RGB image had dimensions:

1536 × 1024 × 3

The reconstructed spectral cube had dimensions:

1536 × 1024 × 31

The reconstructed cube was stored as float32 data.

The reconstructed output was successfully validated for:

- Correct spatial dimensions.
- 31 spectral bands.
- Finite numerical values.
- Compatibility with the visualization functions.


7. GROUND-TRUTH VISUALIZATION
-----------------------------

A Hyper-Skin held-out subject was also used to demonstrate comparison
between AI-estimated spectral information and available ground-truth VIS
data.

The comparison demonstrates that reconstructed spectra can be inspected
against paired spectral measurements when such reference data exist.

The visualization also shows that reconstruction errors vary across
wavelengths.

In particular, larger reconstruction errors were observed in several
higher-wavelength bands, especially toward approximately 630–700 nm in
the Module J validation experiments.

These observations are technical reconstruction findings only and should
not be interpreted as biological or clinical findings.


8. IMPORTANT INTERPRETATION LIMITATIONS
----------------------------------------

The spectral images displayed by this module are AI-estimated
reconstructions from RGB input.

They are NOT equivalent to measurements acquired directly from a
hyperspectral or multispectral camera.

The false-color representation is a visualization technique and does not
represent a real camera channel configuration.

A visible pattern in a reconstructed spectral band does not automatically
represent inflammation, pigmentation, hemoglobin abnormality, collagen
change, acne, or any other medical condition.

No disease label or clinical conclusion is generated by Module K.


9. RELATION TO PREVIOUS MODULES
-------------------------------

Module K depends on the output of Module I, RGB-to-spectral reconstruction.

The processing flow is:

   ↓
Image Quality Assessment
   ↓
Skin Segmentation
   ↓
Region/Candidate Localization
   ↓
RGB-to-Spectral Reconstruction
   ↓
AI-Estimated 31-Band VIS Cube
   ↓
Spectral Visualization
   ↓
Band Views / Spectral Curves / Comparisons


10. SAFETY AND SCIENTIFIC BOUNDARIES
------------------------------------

The visualization module follows the following boundaries:

- AI-estimated spectra are explicitly identified as estimates.
- The output is not described as actual NIR imagery.
- Visualization does not imply disease diagnosis.
- Reconstruction error is not treated as disease probability.
- Ground-truth comparisons are used for technical validation.
- No unsupported biological interpretation is assigned to individual
  reconstructed wavelengths.
- Uncertainty and reconstruction limitations remain important for all
  downstream interpretation.
